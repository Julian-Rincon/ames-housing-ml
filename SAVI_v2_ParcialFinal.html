Bloque 3 · Reinforcement Learning

Diseño del ambiente RL

MDP(S, A, P, R, γ) donde S=clusters, A={APROBAR, REVISAR, RECHAZAR}, R calibrada con costos reales de tasación

Función de recompensa R(s,a) — basada en costos reales
APROBAR: error < 10%  +$200  (valuación correcta)
APROBAR: error < 25%  −$500  (corrección moderada)
APROBAR: error ≥ 25%  −$2,000 (litigio potencial)
REVISAR: error < 10%  −$150  (tiempo perdido)
REVISAR: error ≥ 10%  −$50   (revisión útil)
RECHAZAR: error > 20% +$50   (correcto pedir datos)
RECHAZAR: error ≤ 20% −$200  (rechazó sin razón)
R[s][a] promedio — tabla completa
Componentes del MDP
S = {S0, S1, S2, S3, S4, S5} — 6 clusters K-Means
A = {APROBAR, REVISAR, RECHAZAR}
P(s'|s) = transiciones históricas contadas del dataset temporal
R(s,a) = f(error XGBoost, acción) promediado por cluster
γ = 0.95  ·  θ = 0.0001
RL Método 1 · Baseline

MDP + Value Iteration

Solución analítica mediante ecuación de Bellman — γ=0.95 · θ=0.0001 · Convergió en 259 iteraciones

value_iteration.py · Ecuación de Bellman
V = {s: 0 for s in STATES} # V(s) inicial = 0
while True:   delta = 0   V_new = V.copy()   for s in STATES:     q_sa = {}     for a in ACTIONS:       efv = sum(P[s][ns] * V[ns]               for ns in P[s])
      # Bellman: Q(s,a) = R(s,a) + γ·E[V(s')]       q_sa[a] = R[s][a] + GAMMA * efv
    V_new[s] = max(q_sa.values())     delta = max(delta, abs(V[s] - V_new[s]))   V = V_new   if delta < THETA: break # 259 iteraciones ✓
# Extraer política óptima π = {s: argmax Q(s,a) for s in STATES}
V*(s) — Valor óptimo por estado

Aprende de experiencia (off-policy) sin conocer el modelo del ambiente — 8,000 episodios · ε-greedy decay

q_learning.py · Actualización Q
Q = {s: {a: 0.0 for a in ACTIONS}     for s in STATES} # Q-table inicial eps = 1.0 # exploración inicial
for ep in range(8000):   for predio in dataset_rl:     s = predio.cluster     # ε-greedy     if random() < eps:       a = random_action() # explora     else:       a = argmax(Q[s]) # explota
    r = calc_reward(err_xgb, a)     s_prime = next_state(s) # muestra P(s'|s)
    # Actualización Bellman off-policy     Q[s][a] += α * (r + γ*max(Q[s_prime]) - Q[s][a])
  eps = max(0.05, eps * 0.995) # decaimiento
# Misma política que VI ✓ (converge al mismo óptimo)

RL Método 3 · Motivación

De Q-Learning a Deep Q-Networks

La limitación del espacio tabular: cuando el estado es continuo, no se puede construir una tabla Q[s][a]

1
Q-Learning tabular
Estado = cluster (0–5). Q-table 6×3 = 18 valores. Funciona, pero pierde toda la información dentro del cluster. Dos predios en S2 con perfiles muy diferentes reciben el mismo tratamiento.
2
Problema: espacio de estado continuo
El predio real tiene 20+ features continuas. Discretizar las combinaciones es inviable (maldición de la dimensionalidad). Se necesita un aproximador de función.
3
Solución: Q(s,a) ≈ QNetwork(s; θ)
DQN reemplaza la tabla por una red neuronal. Entrada: vector 20D de features. Salida: Q-values para cada acción. La red aprende una política generalizable a predios no vistos.

class QNetwork(nn.Module):   def __init__(self, state_dim):     self.net = nn.Sequential(       nn.Linear(state_dim, 128),       nn.BatchNorm1d(128),       nn.ReLU(),       nn.Dropout(0.2),       nn.Linear(128, 64),       nn.ReLU(),       nn.Linear(64, 3) # 3 acciones     )
# Loop de entrenamiento (150 épocas) for epoch in range(150):   for predio in shuffle(dataset):     state = top20_features(predio) # 20D     a = agent.act(state) # ε-greedy     reward = calc_reward(xgb_err, a)     agent.remember(state, a, reward, ...)
    # Minimiza Huber(Q_online, Q_target)     loss = agent.learn()
    # Target net ← online net cada 200 pasos     if step % 200 == 0:       target.load_state_dict(online.state_dict())

Interpretación de los resultados
VI y Q-Learning convergen 100%: esperado — ambos trabajan en el mismo espacio discreto (6 clusters). Q-Learning aprende de experiencia lo que VI calcula analíticamente.
DQN mejora reward (−57.1 vs −58.2): al operar en espacio continuo, encuentra matices dentro de cada cluster. Un predio en S0 con OverallQual=9 puede recibir APROBAR aunque S0 normalmente REVISA.
DQN generaliza a predios nuevos: la red neuronal puede evaluar cualquier predio sin necesidad de asignarle un cluster — solo necesita sus 20 features numéricas.

Solicitar más datos — 3.5% del mercado
R(APROBAR)=−$2,000 vs R(RECHAZAR)=+$50. El agente descubrió que pedir documentación adicional y esperar produce mayor valor descontado que valuar con incertidumbre alta. La regla más contraintuitiva — emergió sola de Bellman.
